# Streaming & Server-Sent Events (SSE) Protocol

**Target Modules:** `backend/app/chat/service.py`, `backend/app/agent/events.py`, `frontend/lib/streaming.ts`  
**Status:** Production  
**Protocol:** HTTP/1.1 or HTTP/2 Server-Sent Events (`text/event-stream`)

---

## 1. Streaming Protocol Overview

Voltix delivers low-latency conversational responses, tool execution logs, live thinking indicators, and multi-agent state updates via Server-Sent Events (SSE). Clients open a single persistent HTTP connection to `/api/chat/stream` or `/api/aetherion/chat` and receive standardized event payloads formatted as `data: <JSON>\n\n`.

### Connection Headers:
* `Content-Type`: `text/event-stream`
* `Cache-Control`: `no-cache`
* `Connection`: `keep-alive`
* `X-Accel-Buffering`: `no` (Disables Nginx/reverse-proxy response buffering)

---

## 2. Event Payloads Specification

### 2.1 Token Event (`token`)
Transmits incremental tokens generated by the LLM in real time.
```json
data: {"type": "token", "content": "Transformer "}
```

### 2.2 Status & Activity Event (`status`)
Transmits the current operational stage of the backend orchestrator.
```json
data: {"type": "status", "status": "Searching indexed documents...", "stage": "rag"}
```
Valid `stage` values: `rag`, `tool`, `reasoning`, `llm`, `verification`.

### 2.3 Citations Event (`citations`)
Transmits structured source snippets retrieved by the RAG engine. Emitted before generation tokens start.
```json
data: {
  "type": "citations",
  "citations": [
    {
      "id": 1,
      "source": "[1] Architecture_Report.pdf",
      "filename": "Architecture_Report.pdf",
      "snippet": "Section 3 outlines the distributed actor model...",
      "score": 0.892
    }
  ]
}
```

### 2.4 Tool Invocation Event (`tool_call`)
Emitted when the agent or orchestrator executes an autonomous tool.
```json
data: {
  "type": "tool_call",
  "tool": "math.calculate",
  "input": {"expression": "2 ** 16"},
  "output": 65536,
  "duration_ms": 1.45
}
```

### 2.5 Real-Time Metrics Event (`metrics`)
Transmits latency and generation performance metrics.
```json
data: {
  "type": "metrics",
  "time_to_first_token_ms": 320.5,
  "total_tokens": 482,
  "tokens_per_sec": 42.8
}
```

### 2.6 Completion Event (`done`)
Emitted on successful stream termination, notifying the client to finalize state and update database references.
```json
data: {
  "type": "done",
  "message_id": "msg_98a72b",
  "conversation_id": "conv_34f18c",
  "title": "Transformer Architecture Analysis"
}
```

### 2.7 Error Event (`error`)
Emitted if an exception occurs during stream processing.
```json
data: {
  "type": "error",
  "message": "Tool 'python' exceeded time budget of 15.0s."
}
```

## 3. Client-Side Streaming Architecture (`frontend/lib/streaming.ts`)

The client processes streaming chunks through a non-blocking `ReadableStream` reader using `TextDecoder`:

```typescript
export function streamChat(
  options: SendMessageOptions,
  callbacks: StreamCallbacks
): AbortController {
  const abortController = new AbortController();

  (async () => {
    const response = await fetch(`${API_BASE_URL}/chat/stream`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(options),
      signal: abortController.signal,
    });

    const reader = response.body?.getReader();
    const decoder = new TextDecoder();
    let buffer = "";

    while (true) {
      const { value, done } = await reader.read();
      if (done) break;

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split("\n");
      buffer = lines.pop() || "";

      for (const line of lines) {
        const trimmed = line.trim();
        if (!trimmed.startsWith("data: ")) continue;
        const event = JSON.parse(trimmed.slice(6));

        if (event.type === "token") callbacks.onToken(event.content);
        else if (event.type === "citations") callbacks.onCitations?.(event.citations);
        else if (event.type === "status") callbacks.onStatus?.(event.status, event.stage);
        else if (event.type === "tool_call") callbacks.onToolCall?.(event);
        else if (event.type === "metrics") callbacks.onMetrics?.(event);
        else if (event.type === "done") callbacks.onDone?.(event);
        else if (event.type === "error") callbacks.onError?.(event.message);
      }
    }
  })();

  return abortController;
}
```

## 4. Instant Generation Cancellation (`AbortController`)

Users can halt generation at any point via the `Stop` generation button. The frontend invokes `abortController.abort()`, cleanly closing the HTTP connection. The backend intercepts the disconnect signal via ASGI cancellation and immediately terminates child processes and LLM inference threads without lingering resource leakage.
