```text
+───────────────────────────────────────────────────────────────────────────────────────────────+

| - Settings & Export Modal | - Execution Profile & Tool Center     |                           |
+───────────────────────────┴───────────────────────────────────────┴───────────────────────────+
```

## 2. Model Comparison Studio (`/studio`)

The Model Comparison Studio ([studio/page.tsx](file:///e:/Projects/AI%20&%20ML/domain_specific_qa_system_project/voltix-1/frontend/app/studio/page.tsx)) enables real-time empirical benchmarking:

* **Dual-Pane Execution**: Concurrently sends identical prompts to two selected models (e.g., `aetherion` vs `gpt-oss:120b-cloud`).
* **Live Telemetry Gauges**:
  * **Time to First Token (TTFT)** in milliseconds.
  * **Generation Throughput (TPS)** in tokens per second.
  * **Total Output Tokens** and duration.
* **Benchmark Presets**: One-click test scenarios covering Attention mechanisms, Coding, Complex Reasoning, Long Context, and Agentic Planning.

## 3. SlideOver Inspector (`SlideOver.tsx`)

A drawer positioned on the right side of the screen providing deep visibility into platform operations without cluttering the chat view:

1. **Cited Sources (`SourceInspector.tsx`)**: Displays full bibliographic citations, relevance scores, and direct quotes from ingested files.
2. **Document Chunks (`SourceList.tsx`)**: Inspects chunk indices and character offsets generated by the RAG parser.
3. **Tool Execution Logs**: Real-time inspection of tool parameters, AST evaluation steps, and sandbox exit codes.

---

## 4. Chat Composer & Multi-Modal Controls

The `Composer` component family provides full interactive control:

* **Auto-Resizing Textarea**: Expands naturally up to 200px before scrolling.
* **Slash Menu (`/`)**: Triggers quick commands (`/help`, `/clear`, `/export`, `/settings`, `/calc`, `/python`).
* **Execution Profile Selector**: Toggles between `FAST`, `BALANCED`, `DEEP`, and `MAX` modes.
* **Tool Center Popover**: Toggles specific autonomous tools (Calculator, Python sandbox, Web research, Database inspection).
* **Drag-and-Drop Overlay (`DropOverlay.tsx`)**: Highlights the canvas when dragging files over the window.

---

## 5. Rich Markdown & Mathematical Rendering

* **LaTeX Formulas**: KaTeX parses inline math (`$...$`) and block equations (`$$...$$`) with crisp mathematical typography.
* **Syntax-Highlighted Code Blocks (`CodeBlock.tsx`)**:
  * Language badge and syntax highlighting.
  * One-click copy with feedback state.
  * Line numbering for clear technical discussions.
* **Tables (`TableRenderer.tsx`)**: Formats structured tabular markdown with alternating row highlights and responsive horizontal scroll.

## 6. Custom React Hooks Directory

| Hook | Purpose & Responsibilities |
| :--- | :--- |
| **`useChat`** | Manages message history state, streaming token accumulation, stop cancellation, branching, and optimistic user turns. |
| **`useAgent`** | Manages autonomous Aetherion agent runs, step monitoring, pause/resume/cancel controls, and HITL approval dialogs. |
| **`useConversations`** | Fetches thread lists, executes optimistic deletion/renaming, manages pinned state, and exports sessions. |
| **`useFileUpload`** | Handles drag-and-drop file ingestion, upload progress indicators, validation, and chunk previews. |
| **`useModels`** | Discovers active Ollama models, polls daemon health every 10s, and detects offline fallback states. |
| **`useCommandPalette`** | Intercepts global keyboard shortcuts (`Cmd+K`, `Ctrl+K`, `/`, `Escape`) to open command search. |
| **`useTheme`** | Persists light, dark, and system themes to `localStorage` with flicker-free DOM class injection. |
